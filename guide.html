AI-Guided Web Deployer

A master blueprint designed for your AI assistant to build, initialize, and deploy your custom static website on GitHub Pages.

🤖 System Instruction for the AI Assistant

Dear AI Assistant: You are guiding a non-technical user. Your goal is to execute or walk the user through these steps to successfully set up a static website. If you have terminal access, you can run these commands directly after explaining them, or guide the user in running them.

Execution Plan:
1. Check and install prerequisites (Brew, Git, GitHub CLI).
2. Create a clean project directory and generate a stunning web page.
3. Set up Git, commit, and create a public GitHub repository.
4. Enable GitHub Pages and configure DNS for their custom domain.

1 Install & Verify Prerequisites

Ensure that Homebrew, Git, and the GitHub CLI are installed. On macOS, run the following commands:

# Check for Homebrew, install if missing
which brew || /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install Git and GitHub CLI
brew install git gh
AI Action: Run these commands if permitted, or prompt the user to run them in their terminal. Verify installation with git --version and gh --version.

2 Initialize Project & Create Assets

Create a project directory, generate a modern index.html, and download or generate a custom image/logo (e.g. hero.png).

# Create project directory and navigate into it
mkdir my-website && cd my-website

# Create your asset folder
mkdir assets
AI Action: Create a beautiful, responsive, and modern HTML/CSS page tailored to the user's needs. Use your image generation tool to create a high-quality hero.png image asset and place it inside the project folder. Ensure all local paths are relative (e.g., src="assets/hero.png").

3 Initialize Git & Commit

Initialize a Git repository and commit the newly created files to track changes.

git init
git add .
git commit -m "Initial commit - website setup"
AI Action: Run these commands within the user's project directory. Make sure the default branch is named main using git branch -M main.

4 Authenticate and Create GitHub Repo

Authenticate your GitHub account using the GitHub CLI, and create a public repository.

# Authenticate with GitHub
gh auth login

# Create the repository on GitHub and push local commits
gh repo create --public --source=. --remote=origin --push
AI Action: Guide the user through the interactive gh auth login prompt if they need to log in. Once authenticated, run the repository creation command.

5 Enable GitHub Pages

Turn on GitHub Pages for the repository using the GitHub API via the CLI.

gh api -X POST /repos/{owner}/{repo}/pages -f "source[branch]=main" -f "source[path]=/"
AI Action: Replace {owner} and {repo} with the user's GitHub username and repository name. Run this command to initialize the deployment.

6 Configure Custom Apex Domain

To point a custom root domain (like yourdomain.com) to your new site, configure your DNS provider and update the GitHub repository.

1. Configure DNS Records

Go to your domain registrar (e.g., GoDaddy, Namecheap) and create four A Records pointing to these IP addresses:

Type Name / Host Value / IP Address
A @ 185.199.108.153
A @ 185.199.109.153
A @ 185.199.110.153
A @ 185.199.111.153

2. Add CNAME File to Repository

Create a file named CNAME in your project root containing only your domain name, and push it to GitHub:

echo "yourdomain.com" > CNAME
git add CNAME
git commit -m "Configure custom domain"
git push origin main
AI Action: Help the user write and commit this file. You can also run the following API request to set the CNAME and enforce HTTPS: 
gh api -X PATCH /repos/{owner}/{repo}/pages -f "cname=yourdomain.com" -F "https_enforced=true"
