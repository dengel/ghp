AI-Guided Web Deployer

A master blueprint designed for your AI assistant to locate, prepare, and deploy your existing website on GitHub Pages.

🤖 System Instruction for the AI Assistant

Dear AI Assistant: You are helping a non-technical user set up and publish their existing website on GitHub. Your goal is to guide them step-by-step or use your tool access to perform these steps for them. Proceed sequentially, validating each phase before moving forward.

Execution Plan:
1. Guide the user to register an account at github.com/signup.
2. Verify and install CLI prerequisites (Homebrew, Git, GitHub CLI).
3. Search the user's filesystem to locate their existing web files. Create the project folder at ~/projects/cc/website and copy the files there. Rename the main entrypoint file to index.html.
4. Initialize a Git repository, commit all files, and push to a new public GitHub repository.
5. Enable GitHub Pages and configure the custom Apex domain.

1 Create a GitHub Account

Before starting, you need a free GitHub account to host your website. If you don't have one:

  • Go to github.com/signup and follow the instructions to create your account.
  • Remember your username and email address, as you'll need them in the following steps.
AI Action: Pause and ask the user if they have created an account. Confirm their GitHub username to proceed.

2 Install & Verify Prerequisites

We need to make sure you have the required tools installed on your Mac: Git (version control) and the GitHub CLI (interact with GitHub from the terminal).

# Install Homebrew (if not already installed)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install Git and GitHub CLI
brew install git gh
AI Action: If you have terminal access, verify if git and gh are already installed. If not, run these commands with the user's consent.

3 Locate & Prepare Website Files

Now, let's locate your existing website files on your computer. We will create a fresh directory at ~/projects/cc/website and move your website files there.

AI Action:
  1. Search the user's home directory (Documents, Desktop, Downloads, etc.) for existing HTML, CSS, or JS files.
  2. Once found, create the directory ~/projects/cc/website: 
    mkdir -p ~/projects/cc/website
  3. Copy all the existing website files and assets into this directory.
  4. Identify the main homepage file (e.g., home.html, welcome.html, etc.). Rename it to exactly index.html so GitHub Pages can recognize it. 
    mv ~/projects/cc/website/your_old_main_file.html ~/projects/cc/website/index.html

4 Initialize Git & Commit

Initialize a local Git repository in your new project folder and add all the files.

cd ~/projects/cc/website
git init
git branch -M main
git add .
git commit -m "initial commit"
AI Action: Execute these commands within the ~/projects/cc/website directory. Ensure that all the files are staged and committed properly.

5 Authenticate & Create GitHub Repo

Log in to your GitHub account via the terminal, and push your local repository to a new public GitHub repository.

# Log in to your GitHub account
gh auth login

# Create a new public repository and push your code
gh repo create website --public --source=. --remote=origin --push
AI Action: Guide the user through the interactive gh auth login steps. Once logged in, execute the repository creation and push command.

6 Enable GitHub Pages

Enable GitHub Pages hosting on your newly created repository using the GitHub API.

gh api -X POST /repos/{owner}/website/pages -f "source[branch]=main" -f "source[path]=/"
AI Action: Replace {owner} with the user's GitHub username and execute the command. This will launch your live site under https://{owner}.github.io/website/.

7 Configure Custom Apex Domain

To point your custom domain (e.g., yourdomain.com) to your newly created website, follow these steps:

1. Configure DNS A Records

Log in to your domain registrar (GoDaddy, Namecheap, etc.) and create four A Records pointing to these IP addresses:

Type Name / Host Value / IP Address
A @ 185.199.108.153
A @ 185.199.109.153
A @ 185.199.110.153
A @ 185.199.111.153

2. Add CNAME File to Repository

Create a file named CNAME in your project root, add your domain name to it, and push it to GitHub:

cd ~/projects/cc/website
echo "yourdomain.com" > CNAME
git add CNAME
git commit -m "Configure custom domain"
git push origin main
AI Action: Create and commit the CNAME file. To enforce HTTPS, you can run the following API request: 
gh api -X PATCH /repos/{owner}/website/pages -f "cname=yourdomain.com" -F "https_enforced=true"
